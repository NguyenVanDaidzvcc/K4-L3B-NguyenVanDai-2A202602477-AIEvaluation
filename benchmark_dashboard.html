WINDOWS / POWERSHELL

Run the project

Run commands from the repository root. The dashboard itself is static HTML and opens directly without a development server.

Environment

01 / SETUP
python --version python -m venv .venv .venv\Scripts\Activate.ps1 python -m pip install -r requirements.txt

Requires Python 3.11 or newer. If PowerShell blocks activation, use the course-approved execution policy for your machine or run the venv Python executable directly.

Core checks

02 / VERIFY
python -m pytest tests/ -v python validate_golden_dataset.py

Expected core suite: 41 passed, 1 skipped when the optional reranker is not implemented. Dataset validator should report PASS.

Generate RAG answers

03 / API REQUIRED
Copy-Item .env.example .env # Add OPENAI_API_KEY and OPENAI_MODEL in .env python domain_assistant.py

Only this generation step needs an OpenAI API key. Keep the key in .env; never paste it into source files or commit it.

Evaluate and open UI

04 / RESULTS
python evaluate_answers.py Start-Process .\benchmark_dashboard.html

The evaluator writes artifacts/benchmark_results.json. Import that JSON in the dashboard to refresh benchmark results.

Execution order

Complete code and dataset first. Validate the golden dataset before making API calls. Generate actual answers, then evaluate those saved answers.
